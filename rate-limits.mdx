## API Rate Limits

To ensure fair usage and system stability, the PolyBackTest API enforces per-user rate limits that vary by plan. Limits are applied globally across all your API keys — using multiple keys does not increase your quota.

### Rate Limits by Plan

| Plan | Requests per Second | Requests per Minute |
| :--- | :--- | :--- |
| **Free** | 1 | 60 |
| **Pro** | 10 | 300 |

<Info>
  Free-plan users are limited to **1 request per second**. Pro users can burst up to **10 requests per second**, with a sustained limit of **300 requests per minute**.
</Info>

### Rate Limit Headers

Every API response includes rate limit headers so you can track your usage:

- `X-RateLimit-Limit`: Your maximum allowed requests for the current window.
- `X-RateLimit-Remaining`: The number of requests you have left in the current window.

When rate limited, a `Retry-After` header indicates how many seconds to wait before retrying.

### 429 Too Many Requests

If you exceed your rate limit, the API will return a `429` error:

```json
{
  "error": "Burst limit exceeded. Max 1 requests per second."
}
```

```json
{
  "error": "Rate limit exceeded. Max 300 requests per minute."
}
```

## Coin Access by Plan

ETH and SOL data is available exclusively to **Pro** plan users. Free-plan users can only query BTC data. Attempting to query `coin=eth` or `coin=sol` on a free plan will return a `402` error:

```json
{
  "error": "ETH data is available exclusively for Pro plan users. Upgrade to Pro to access ETH markets, orderbooks, and trades."
}
```

## Plan-Based Market Limits

Access to market data depends on your plan. Free-plan users can access a limited window of the **most recent** BTC markets for each timeframe. Pro users have **unlimited** access to all coins.

### Free Plan Limits

| Market Type | Latest Markets Accessible | Snapshots |
| :--- | :--- | :--- |
| **5m** | 50 | Unlimited (for accessible markets) |
| **15m** | 50 | Unlimited (for accessible markets) |
| **1h** | 24 | Unlimited (for accessible markets) |
| **4h** | 24 | Unlimited (for accessible markets) |
| **24h** | 5 | Unlimited (for accessible markets) |

<Info>
  **"Latest"** means the most recently created markets, sorted by start time. As new markets are created, older ones rotate out of the free-plan window.
</Info>

### What Does This Mean?

- **List Markets (`/v2/markets`)**: Free users will only see markets within the allowed window. If you request more than the limit (e.g., `limit=60` for 5m markets), the API will return only the latest 50 and include a `warning` field in the response.
- **Get Market by ID/Slug**: Accessing a market outside your plan's window returns a `402` error.
- **Snapshots**: Free users can access all snapshots for any market **within** their allowed window. Accessing snapshots for a market outside the window returns a `402` error.

### Check Your Limits

Use the `/v2/limits` endpoint to view your current plan and limits:

```bash
curl -X GET "https://api.polybacktest.com/v2/limits" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```json Example Response (Free Plan)
{
  "plan": "free",
  "limits": {
    "5m_markets": 50,
    "15m_markets": 50,
    "1h_markets": 24,
    "4h_markets": 24,
    "24h_markets": 5,
    "snapshots": null
  },
  "rate_limit": {
    "max_per_second": 1,
    "remaining_per_second": 0,
    "max_per_minute": null,
    "remaining_per_minute": null
  }
}
```

```json Example Response (Pro Plan)
{
  "plan": "pro",
  "limits": {
    "5m_markets": null,
    "15m_markets": null,
    "1h_markets": null,
    "4h_markets": null,
    "24h_markets": null,
    "snapshots": null
  },
  "rate_limit": {
    "max_per_second": 10,
    "remaining_per_second": 9,
    "max_per_minute": 300,
    "remaining_per_minute": 299
  }
}
```

<Note>
  A `null` value for `snapshots` or market limits means there is no cap — Pro users have unlimited access. A `null` value for `max_per_minute` (Free plan) means only the per-second limit applies.
</Note>

### Handling Limit Responses

When your request is clamped by plan limits, the API response will include a `warning` field:

```json
{
  "markets": [...],
  "total": 8500,
  "limit": 60,
  "offset": 0,
  "warning": "Free plan limit reached. Showing latest 50 of 50 allowed markets. Upgrade to Pro to view all markets."
}
```

When you try to access a market outside your plan window, you'll receive a `402` error:

```json
{
  "detail": {
    "error": "upgrade_required",
    "message": "This market is outside your plan's access window. Upgrade to Pro for unlimited access to all market history and snapshots.",
    "current_plan": "free"
  }
}
```

<Tip>
  To handle these gracefully in your code, check for the `warning` field in successful responses and handle `402` status codes for individual market/snapshot requests.
</Tip>

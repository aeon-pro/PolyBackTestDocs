## Polymarket Up/Down Markets

Currently, the PolyBackTest API tracks Polymarket prediction markets for the following cryptocurrencies:

| Coin | Query Parameter `coin` | Supported Market Types | Plan |
| :--- | :--- | :--- | :--- |
| **Bitcoin** | `btc` | `5m`, `15m`, `1hr`, `4hr`, `24hr` | Free & Pro |
| **Ethereum**| `eth` | `5m`, `15m`, `1hr` | Pro only |
| **Solana**  | `sol` | `5m`, `15m`, `1hr` | Pro only |

<Info>
As new assets (like XRP) are added to the platform, their supported market types will be listed here.
</Info>

<Warning>
**ETH data collection started on 2026-03-02** Full 31-day historical coverage for Ethereum is not yet available.
</Warning>

<Warning>
**SOL data collection started on 2026-03-16.** Full 31-day historical coverage for Solana is not yet available.
</Warning>

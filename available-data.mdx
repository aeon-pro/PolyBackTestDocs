## Polymarket Up/Down Markets

Currently, the PolyBackTest API tracks Polymarket prediction markets for the following cryptocurrencies:

| Coin | Query Parameter `coin` | Supported Market Types |
| :--- | :--- | :--- |
| **Bitcoin** | `btc` | `5m`, `15m`, `1hr`, `4hr`, `24hr` |
| **Ethereum**| `eth` | `5m`, `15m`, `1hr` |

<Info>
As new assets (like SOL or XRP) are added to the platform, their supported market types will be listed here.
</Info>

<Warning>
**ETH data collection started on 2026-03-02T10:20:00Z.** Full 31-day historical coverage for Ethereum is not yet available.
</Warning>

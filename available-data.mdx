## Polymarket Up/Down Markets

Currently, the PolyBackTest API tracks Polymarket prediction markets for the following cryptocurrencies:

| Coin | v4 `coin` value | Supported Market Types | Plan |
| :--- | :--- | :--- | :--- |
| **Bitcoin** | `btc` | `5m`, `15m`, `1h`, `4h`, `24h` | Free & Pro |
| **Ethereum**| `eth` | `5m`, `15m`, `1h` | Pro only |
| **Solana**  | `sol` | `5m`, `15m`, `1h` | Pro only |

<Tip>
v4 URLs use a query parameter: `GET /v4/markets?coin=btc&market_type=5m&limit=10`.
</Tip>

<Info>
As new assets (like XRP) are added to the platform, their supported market types will be listed here.
</Info>

<Info>
Historical access is plan-limited across supported Polymarket crypto data: 31 days by default, or 60 days with the extended-history Pro add-on or Dedicated/Enterprise plans. See [Rate Limits & Plans](/rate-limits#historical-data-limits).
</Info>

## Welcome to PolyBackTest

PolyBackTest provides access to Polymarket crypto Up/Down markets, Chainlink reference prices, and historical snapshots for building strategies and backtests.

## Quick examples

Fetch the latest BTC prediction markets:

```bash
curl "https://api.polybacktest.com/v4/markets?coin=btc&market_type=5m&limit=10" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Get the first page of snapshots for a market:

```bash
curl "https://api.polybacktest.com/v4/markets/1051520/snapshots?coin=btc&limit=100" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

<Info>
v4 keeps the familiar `coin` query parameter and `limit`/`offset` pagination. Supported coins are `btc`, `eth`, and `sol`.
</Info>

<Note>
v2 and v3 remain available for existing integrations. New integrations should use [API v4](/api-reference/v4/overview).
</Note>

## Quick examples

Fetch the latest BTC prediction markets:

```bash
curl "https://api.polybacktest.com/v3/btc/markets?type=5m&limit=10" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Get the latest BTC spot orderbook:

```bash
curl "https://api.polybacktest.com/v3/btc/spot/latest" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

<Info>
v3 puts the coin in the URL path (`/v3/{coin}/...`). Supported coins: `btc`, `eth`, `sol`. Each request targets one coin.
</Info>

<Note>
If you're still on v2 (`/v2/markets?coin=btc&...`), it keeps working through the sunset window — see the [v2 → v3 migration guide](/api-reference/v3/overview).
</Note>

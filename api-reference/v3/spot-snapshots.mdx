---
title: 'Spot - List Snapshots'
openapi: 'GET /v3/{coin}/spot/snapshots'
---

Cursor-paginated Binance spot order book snapshots for `{coin}USDT`. Sorted newest first. Bounded by `start_time` and `end_time` (ms epoch or ISO-8601). Default `limit` 100, max 1000.

If `start_time` is omitted, the API starts at the oldest timestamp your plan can access. Explicit timestamps older than your history window return `403 HISTORY_LIMIT_EXCEEDED`.

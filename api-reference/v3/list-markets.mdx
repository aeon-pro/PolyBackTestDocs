---
title: 'List Markets'
openapi: 'GET /v3/{coin}/markets'
---

## What you get

Cursor-paginated markets for `{coin}` (btc, eth, or sol), newest first.

<Info>Use `type=5m|15m|1h|4h|24h` to filter by market interval. Omit it to see every market type the coin publishes.</Info>

## Pagination

Pass `pagination.next_cursor` from one response as `?cursor=` on the next request. Stop when `pagination.has_more === false`. `total_count` is only included when you pass `?include_count=true`.

<Tip>For backtest-style deep history, cursor pagination stays O(1) at any depth and uses the same indexes. Keep sending the cursor forward without bouncing back to offset.</Tip>

## Plan access

- **Free**: limited to the most recent N markets per coin × type, inside the default 31-day history window.
- **Pro**: all included markets inside the purchased history window (31 days by default, 60 days with the extended-history add-on).
- **Dedicated / Enterprise**: all included crypto markets inside the 60-day history window.

If `start_time` is omitted, the API starts from the oldest timestamp your plan can access. An explicit `start_time` older than that returns `403 HISTORY_LIMIT_EXCEEDED`.

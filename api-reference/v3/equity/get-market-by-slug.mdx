---
title: 'Get Equity Market by Slug'
openapi: 'GET /v3/equity/{symbol}/markets/by-slug/{slug}'
---

## What you get

Same payload as [Get Equity Market](/api-reference/v3/equity/get-market), but keyed by the URL-friendly slug (e.g. `spx-up-or-down-on-april-28-2026`).

## Example

```bash
curl 'https://api.polybacktest.com/v3/equity/spx/markets/by-slug/spx-up-or-down-on-april-28-2026' \
  -H "X-API-Key: $POLY_KEY"
```

<Tip>Slugs are stable per market — prefer them for any external link you control. Internally, prefer `market_id` for joins.</Tip>

<Info>404 → `MARKET_NOT_FOUND`. Plan-gating behaves the same as the by-ID variant, and markets older than the fixed 31-day equity history window return `403 HISTORY_LIMIT_EXCEEDED`.</Info>

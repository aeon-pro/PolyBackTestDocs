---
title: 'Equity Snapshot at Timestamp'
openapi: 'GET /v3/equity/{symbol}/markets/{market_id}/snapshots/at/{timestamp}'
---

## What you get

The single snapshot **closest to** `{timestamp}` (millisecond epoch or ISO-8601), bundled with the parent market record so the response is self-contained.

```json
{
  "data": {
    "market": { "market_id": "1054321", "symbol": "spx", "...": "..." },
    "snapshot": {
      "time": "2026-04-28T15:30:00Z",
      "price": 5247.83,
      "price_up": 0.61,
      "price_down": 0.39
    }
  },
  "meta": { "request_id": "req_...", "timestamp": "2026-04-28T15:30:30Z" }
}
```

## Tolerance

Returns `404 SNAPSHOT_NOT_FOUND` if no snapshot lies within **2 seconds** of the requested time. The window is intentionally tight — snapshots are written every second during active hours, so a 2-second miss usually means the market wasn't yet collecting (pre-open) or had already settled.

<Info>Equity snapshot history is fixed at 31 days. A `{timestamp}` older than that returns `403 HISTORY_LIMIT_EXCEEDED`.</Info>

## Example

```bash
# ms epoch
curl 'https://api.polybacktest.com/v3/equity/spx/markets/1054321/snapshots/at/1745846400000' \
  -H "X-API-Key: $POLY_KEY"

# ISO-8601 — URL-encode the colons or quote the URL
curl 'https://api.polybacktest.com/v3/equity/spx/markets/1054321/snapshots/at/2026-04-28T15:30:00Z' \
  -H "X-API-Key: $POLY_KEY"
```

<Tip>Use this to align backtest decisions to a specific wall-clock moment without scanning a whole snapshot window. For pre/post-market alignment to the **underlying** rather than the market book, see [Equity Price at Timestamp](/api-reference/v3/equity/price-at) — it has a wider 60s tolerance.</Tip>

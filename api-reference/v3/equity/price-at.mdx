---
title: 'Equity Price at Timestamp'
openapi: 'GET /v3/equity/{symbol}/prices/at/{timestamp}'
---

## What you get

The closest underlying price tick to `{timestamp}` (millisecond epoch or ISO-8601). Returns `404 PRICE_NOT_FOUND` if no tick is within **60 seconds** of the requested time.

<Warning>Always returns `404` for `spx` and `spx-open` — Polymarket does not publish an SPX index tick feed.</Warning>

## Example

```bash
curl 'https://api.polybacktest.com/v3/equity/spx/prices/at/1745846400000' \
  -H "X-API-Key: $POLY_KEY"
```

```json
{
  "data": {
    "id": 482910,
    "symbol": "spx",
    "price": 5247.83,
    "source_ts": "2026-04-28T15:30:00.250Z",
    "received_ts": "2026-04-28T15:30:00.281Z"
  },
  "meta": { "request_id": "req_...", "timestamp": "2026-04-28T15:30:30Z" }
}
```

## Why a 60-second tolerance

Equity ticks are sparser than CLOB snapshots — outside regular trading hours the upstream feed can pause for minutes at a time. The wider 60-second window lets you ask "what was SPX at 15:30:00" without falling off a cliff if the nearest tick happened to land at 15:29:55. The matching snapshot endpoint uses a **2-second** window for comparison; pick the one that matches the data shape you actually need:

| You want… | Use |
|---|---|
| The order-book state at a moment | [Snapshot at Timestamp](/api-reference/v3/equity/snapshot-at) (2 s) |
| The underlying price at a moment | This endpoint (60 s) |

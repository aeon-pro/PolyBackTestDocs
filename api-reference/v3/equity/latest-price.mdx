---
title: 'Latest Equity Price'
openapi: 'GET /v3/equity/{symbol}/prices/latest'
---

## What you get

The single most recent underlying price tick for `{symbol}`. Cached for ~1 second so high-RPS callers don't repeatedly hit the database.

## Example

```bash
curl 'https://api.polybacktest.com/v3/equity/spx/prices/latest' \
  -H "X-API-Key: $POLY_KEY"
```

```json
{
  "data": {
    "id": 482910,
    "symbol": "spx",
    "price": 5247.83,
    "source_ts": "2026-04-28T15:30:00.250Z",
    "received_ts": "2026-04-28T15:30:00.281Z"
  },
  "meta": { "request_id": "req_...", "timestamp": "2026-04-28T15:30:00Z" }
}
```

<Info>Returns `404 PRICE_NOT_FOUND` if no tick has ever been recorded for this symbol — typically only on a brand-new deployment before the collector has seen its first tick. **Always 404 for `spx` and `spx-open`** since Polymarket does not publish an SPX tick stream.</Info>

<Tip>This is the right endpoint for "what's the spot value right now" widgets. For a tick at a specific moment, use [Equity Price at Timestamp](/api-reference/v3/equity/price-at).</Tip>

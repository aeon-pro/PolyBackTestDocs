---
title: 'List Equity Markets'
openapi: 'GET /v3/equity/{symbol}/markets'
---

## What you get

Cursor-paginated list of daily Up/Down equity markets for `{symbol}`, newest first. Each market represents one trading-day Up/Down outcome on the underlying.

| Symbol | Underlying | Underlying-price feed | Notes |
|---|---|---|---|
| `spx` | S&P 500 index | ❌ none | Close-settled. `price_start`, `price_end`, and per-snapshot `price` are always `null` — Polymarket doesn't publish an SPX tick stream. Winner still resolves correctly. |
| `spx-open` | S&P 500 index | ❌ none | Open-settled. Same NULL-price caveat as `spx`. |
| `spy` | SPDR S&P 500 ETF | ✅ | Close-settled. |
| `wti` | WTI crude oil (front-month) | ✅ | Close-settled. |
| `xauusd` | Spot gold | ✅ | Close-settled. |

<Info>Equity markets are **daily only**. There is no `type` filter, and the `market_type` field is not present in the response.</Info>

<Warning>For `spx` and `spx-open`, the underlying-price columns (`price_start`, `price_end`, `equity_snapshots.price`) are permanently `null` because Polymarket does not expose an SPX index tick feed. The CLOB-derived fields (`price_up`, `price_down`, `winner`, `final_volume`, `final_liquidity`) are populated normally. If you need an SPX reference price, fetch it from your own market-data source and join on `start_time` / `end_time`.</Warning>

## Example

```bash
curl 'https://api.polybacktest.com/v3/equity/spx/markets?limit=25' \
  -H "X-API-Key: $POLY_KEY"
```

## Pagination

Pass `pagination.next_cursor` from one response as `?cursor=` on the next request. Stop when `pagination.has_more === false`. `total_count` is only included when you pass `?include_count=true` (it triggers a `COUNT(*)` — leave it off unless you need it).

## Filters

- `?resolved=true|false` — only resolved or only open markets.
- `?start_time=` / `?end_time=` — bound the window in `start_time` (ms epoch or ISO-8601).

## Plan access

- **Free** — equity data is **Pro-only**. Free keys receive `402 PLAN_UPGRADE_REQUIRED` from the worker, or `403 COIN_NOT_IN_PLAN` (with `details.symbol`) at the gateway.
- **Pro / Enterprise** — unlimited history.

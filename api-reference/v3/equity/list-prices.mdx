---
title: 'List Equity Price Ticks'
openapi: 'GET /v3/equity/{symbol}/prices'
---

## What you get

Latest-first stream of raw underlying price ticks for `{symbol}`, sourced from the Polymarket RTDS WebSocket feed that Polymarket itself uses to settle each market. Useful for back-testing strategies against the exact price the market is settled on — not a third-party reference price.

<Warning>Not available for `spx` or `spx-open`. Polymarket does not publish an SPX index tick stream on RTDS, so this endpoint returns an empty `data` array for those symbols. `spy`, `wti`, and `xauusd` work normally.</Warning>

## Example

```bash
curl 'https://api.polybacktest.com/v3/equity/spx/prices?limit=200' \
  -H "X-API-Key: $POLY_KEY"
```

```json
{
  "data": [
    {
      "id": 482910,
      "symbol": "spx",
      "price": 5247.83,
      "source_ts": "2026-04-28T15:30:00.250Z",
      "received_ts": "2026-04-28T15:30:00.281Z"
    }
  ],
  "pagination": { "next_cursor": "...", "has_more": true, "limit": 200, "count": 200 },
  "meta": { "request_id": "req_...", "timestamp": "2026-04-28T15:30:00Z" }
}
```

## Pagination & filters

- Latest-first. Pass `pagination.next_cursor` forward to walk further into the past.
- `limit` defaults to 100, max 1000.
- `?start_time=` / `?end_time=` (ms epoch or ISO-8601) bound the window in `source_ts`.

## Field meanings

| Field | Notes |
|---|---|
| `source_ts` | Timestamp from the upstream feed — what you should join on. |
| `received_ts` | When the equity-price collector ingested the tick. The gap to `source_ts` is the ingestion latency (typically < 100 ms). |
| `price` | Underlying price. Decimal precision varies by symbol. |

<Note>Equity ticks are sparser than CLOB snapshots — outside trading hours there can be long gaps. That's expected: the collector only writes on actual feed updates.</Note>

---
title: 'Get Market by Slug'
openapi: 'GET /v4/markets/by-slug/{slug}'
---

Returns the same market object as the by-ID endpoint, selected using its Polymarket slug.

```bash
curl "https://api.polybacktest.com/v4/markets/by-slug/bitcoin-up-or-down-may-1?coin=btc" \
  -H "X-API-Key: $POLY_KEY"
```

A market older than the authenticated key's 31-, 60-, or 120-day history
window returns `403 HISTORY_LIMIT_EXCEEDED`.

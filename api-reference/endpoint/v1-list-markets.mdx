## Overview

This endpoint returns all available prediction markets. Use the filtering parameters to narrow down results by market type or resolution status.

<Note>Markets are sorted by start time in descending order, so you'll see the newest markets first.</Note>

<Info>Learn how to query effectively using time filters and pagination limits in our [Fetching Data & Pagination](/fetching-data) guide.</Info>

<Info>Check the [Available Data & Markets](/available-data) guide to see which market types are supported for each coin.</Info>

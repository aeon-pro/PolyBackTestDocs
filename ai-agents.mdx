## Overview

PolyBackTest provides a machine-readable API reference designed specifically for LLM consumption. Add one line to your agent's system prompt and it can autonomously discover endpoints, authenticate, paginate results, and build trading strategies.

This works with any LLM or agent framework — Claude, GPT, Gemini, LangChain, CrewAI, AutoGen, or your own custom agent.

## How It Works

<Steps>
  <Step title="Get an API Key">
    Create a key in your [Dashboard](https://polybacktest.com/dashboard). Your agent will use this to authenticate all requests.
  </Step>
  <Step title="Add the System Prompt">
    Paste the instruction below into your agent's system prompt or context window. It points to a machine-readable reference document that contains everything the agent needs.
  </Step>
  <Step title="Let It Query">
    Your agent can now discover endpoints, understand response schemas, paginate results, and build strategies autonomously.
  </Step>
</Steps>

## System Prompt

Copy this into your agent's system prompt or tool configuration. The linked document contains complete endpoint specs, authentication details, request examples, and response schemas.

<CodeGroup>
```text System Prompt
You have access to the PolyBackTest Data API for querying real-time and historical prediction market data, cryptocurrency orderbooks, and aggregated trades. For complete endpoint documentation, authentication, parameter reference, response schemas, and usage examples, refer to: https://polybacktest.com/llms
```

```python Python Agent Example
import openai

client = openai.OpenAI()

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {
            "role": "system",
            "content": (
                "You have access to the PolyBackTest Data API for querying "
                "real-time and historical prediction market data, cryptocurrency "
                "orderbooks, and aggregated trades. For complete endpoint "
                "documentation, authentication, parameter reference, response "
                "schemas, and usage examples, refer to: "
                "https://polybacktest.com/llms"
            ),
        },
        {
            "role": "user",
            "content": "Get the latest BTC prediction markets and their snapshots",
        },
    ],
)
```

```typescript TypeScript Agent Example
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();

const message = await client.messages.create({
  model: "claude-sonnet-4-20250514",
  max_tokens: 4096,
  system:
    "You have access to the PolyBackTest Data API for querying " +
    "real-time and historical prediction market data, cryptocurrency " +
    "orderbooks, and aggregated trades. For complete endpoint " +
    "documentation, authentication, parameter reference, response " +
    "schemas, and usage examples, refer to: " +
    "https://polybacktest.com/llms",
  messages: [
    {
      role: "user",
      content: "Get the latest BTC prediction markets and their snapshots",
    },
  ],
});
```
</CodeGroup>

<Tip>
  The `https://polybacktest.com/llms` URL returns a plain-text markdown document optimized for LLM context windows. It includes all endpoints, parameters, authentication instructions, and response schemas in a compact format.
</Tip>
